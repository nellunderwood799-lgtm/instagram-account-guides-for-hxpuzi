# Instagram 账号选购文章库

本仓库包含 300 篇中文 Instagram 账号选购与交付说明文章，所有文章均直接放在仓库根目录，与本 README 同层。

每篇正文约 400–600 字符。文章采用短篇连续段落，涵盖账号类型、商品规格比较、交付资料、售后范围和交易风险等主题。

文章中的火星铺子文字入口和封面图均跳转至 [火星铺子](https://hxpuzi.com/?utm_source=github)，并带有 `utm_source=github` 参数。封面文件位于 [`images/instagram-cover.svg`](images/instagram-cover.svg)。

文章标题与正文字符数索引见 [`文章目录.csv`](文章目录.csv)。
